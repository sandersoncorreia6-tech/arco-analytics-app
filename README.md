# ARCO Analytics

Plataforma Flutter/Dart de inteligência para treinadores de basquete.

## Versão
`0.5.0+5`

## Plataformas
- Android: APK e AAB assinados
- iPhone/iPad: Web/PWA
- PC/Mac: Web/PWA

## Android identity
Application ID fixo: `com.arcoanalytics.app`

## Recursos atuais
- Coach Hub
- login demo do treinador Adriano Mião / Tupã–Monstrinho
- dashboard com insights
- calendário/Hub FPB + LBC
- detalhes de partidas
- vínculo de vídeos do YouTube
- scout, lineups, métricas e analytics
- conectores FPB/LBC isolados
- Web/PWA
